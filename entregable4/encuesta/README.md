# Encuesta NivelaTec (Google Forms)

Encuesta de 4 minutos para estudiantes de CFT, IP o universidad (18 años o más). Sirve para reemplazar con datos reales la parte simulada del Entregable 3.

## Crear el formulario (2 minutos)

1. Entra a https://script.google.com con tu cuenta de Google y pulsa **Nuevo proyecto**.
2. Borra lo que aparece y pega todo el contenido de `crear_encuesta_nivelatec.gs`.
3. Pulsa **Ejecutar** (función `crearEncuesta`). La primera vez Google pide permisos: **Revisar permisos → tu cuenta → Configuración avanzada → Ir al proyecto → Permitir**.
4. Abre **Registro de ejecución**: aparecen el enlace para responder, el de edición y la hoja de respuestas. Todo queda también en tu Google Drive.
5. Para que tu equipo pueda editarla: abre el formulario → menú ⋮ → **Agregar colaboradores**.

## Contenido

| Sección | Preguntas | Para qué sirve en el informe |
|---|---|---|
| Consentimiento | Acepta y es mayor de 18 (si dice que no, termina) | Ética |
| Sobre ti | Institución, año, área, tipo de colegio, primera generación, trabajo | Segmento de clientes |
| Primeras evaluaciones | Resultado de la primera prueba, cuándo notó la brecha, seguridad por tema (1–5), uso de nivelación y barreras | Problema (P1–P3) |
| Posible solución | Utilidad (1–5), aviso al docente, dónde hacer el diagnóstico, dispositivo, pregunta abierta | Propuesta de valor y canales |
| Prototipo (opcional) | Si quiere probar el MVP y un contacto | Reclutar 10 personas para la prueba del Anexo B |

Meta: 30 respuestas o más. Para el informe, filtra por quienes estudian en CFT o IP.
